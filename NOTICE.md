# Notice

## Données de zones

`ZoneCreatures.lua` (créatures de chaque zone) et `ZoneGathering.lua` (herbes et minerais de chaque zone) sont dérivés de la base de données de [Questie](https://github.com/Questie/Questie), publiée dans le dépôt [Questie/QuestieDB](https://github.com/Questie/QuestieDB) (données importées de Questie). Ces données sont sous licence [GPL-3.0](https://www.gnu.org/licenses/gpl-3.0.html) (voir le `LICENSE.md` de QuestieDB).

Les deux fichiers sont générés par `tools/gen_zone_data.py` (Python 3, sans dépendance) à partir d'une copie locale de QuestieDB :

```
python3 -I tools/gen_zone_data.py /chemin/vers/QuestieDB --commit <sha> --date AAAA-MM-JJ
```

Ne les édite pas à la main : relance le script. L'en-tête de chaque fichier donne le commit de QuestieDB utilisé et la date de génération.
