# Notice

## Données de zones

Six fichiers de l'addon sont dérivés de la base de données de [Questie](https://github.com/Questie/Questie), publiée dans le dépôt [Questie/QuestieDB](https://github.com/Questie/QuestieDB) (données importées de Questie), une paire par client :

| Fichier | Contenu |
| --- | --- |
| `ZoneCreatures_Era.lua`, `ZoneCreatures_Forever.lua` | créatures de chaque zone |
| `ZoneGathering_Era.lua`, `ZoneGathering_Forever.lua` | herbes et minerais de chaque zone |
| `ZoneQuests_Era.lua`, `ZoneQuests_Forever.lua` | quêtes de chaque zone (niveau, niveau requis, races, classes, noms français et anglais, quêtes exclusives) |

Chaque fichier se garde lui-même : seul celui de ton client (Classic Era ou WoW Forever) construit sa table. Aucun addon tiers n'est requis en jeu : les quêtes ne sont plus lues dans Questie.

Ces données sont sous licence [GPL-3.0](https://www.gnu.org/licenses/gpl-3.0.html) (voir le `LICENSE.md` de QuestieDB).

### Couches appliquées

- **Era** : données `data/Classic/` brutes. Les quêtes reçoivent en plus les corrections statiques d'Era (`src/corrections/Era/classicQuestFixes.lua`). Créatures et récolte restent brutes.
- **Forever** : données `data/Forever/`, puis les couches statiques dans l'ordre de QuestieDB (`docs/forever.md`, `src/config.lua`) : corrections Era héritées (`src/corrections/Forever/legacy/`), delta-base générée (`generated/`), traces (`traces/`), corrections Forever écrites à la main (`forever*Fixes.lua`). Zones et sous-zones : `support/Forever/Zones/`. Les zones propres à Forever (Zephras Isle, Riverglades, Shen'dralas, Darkspear Islands, Mount Hyjal) sont incluses.
- **Les deux** : seules les corrections statiques (`Load`) s'appliquent ; les corrections dynamiques (selon la faction ou le personnage) ne sont pas lues. Les quêtes cachées par Questie (`QuestieQuestBlacklist`, sauf `HIDE_ON_MAP`) et les quêtes d'événements saisonniers (`Holidays/quests`) viennent du dépôt [Questie/Questie](https://github.com/Questie/Questie) (GPL-3.0), passé en option `--questie-src`.

### Générer

Ces données ont été importées une fois de QuestieDB (commit `c5de61ab`, Questie 12.4.0) dans **notre** base, `data/` à la racine du dépôt, où on les corrige et les complète (`data/<client>/fixes.json`). Les fichiers de l'addon sont générés depuis `data/` seulement, par `tools/gen_zone_data.py` (Python 3, sans dépendance, sortie déterministe) :

```sh
python3 -I tools/gen_zone_data.py
```

Voir `docs/DONNEES.md` : contenu de la base, corrections, reprise facultative des nouveautés de Questie (`tools/import_questie.py`).

## Zone data (English)

`ZoneCreatures_<Era|Forever>.lua`, `ZoneGathering_<Era|Forever>.lua` and `ZoneQuests_<Era|Forever>.lua` are generated by `tools/gen_zone_data.py` from our own database (`data/`), imported once from Questie's database (Questie/QuestieDB, GPL-3.0; quest blacklist and seasonal event lists from Questie/Questie, GPL-3.0) and maintained in this repository. Era uses raw Classic data (plus Era static quest corrections); Forever applies QuestieDB's static layers in order: inherited legacy corrections, generated delta-base, traces, authored Forever corrections. Each file only builds its table on its own client. Do not edit them by hand.
